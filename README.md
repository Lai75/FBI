# 聊回忆 — 私人聊天回忆助手（本地版 MVP）

根据《私人聊天回忆助手-需求文档.md》实现的 Sprint 1 核心版本：**原文私密库**。

只做原文的保存与检索，不含账户系统（本机即隐私边界）、不含人物别名实体、不含 AI 自动整理——这些是需求文档中 Sprint 2/3 的范围，本版本刻意不做，先把"可靠找回原话"这一件事做扎实。

## 功能

- 粘贴聊天文本，或上传 `.txt` / `.csv` 文件（≤10MB）
- 自动解析时间、发送人、正文（支持微信 PC 导出格式、通用单行格式、CSV），无法识别的内容标记"待确认"，保存前可逐条编辑修正
- 按关键词、发送人（人物）、日期范围搜索，命中原始消息可查看上下文
- 按批次浏览时间线、软删除 + 回收站（恢复 / 彻底删除）
- 一键导出全部数据为 JSON 文件

## 使用方法

```bash
npm install
npm start
```

然后在浏览器打开 **http://127.0.0.1:3000**（仅监听本机，不会暴露到局域网/公网）。

## 数据存放

所有数据保存在本地文件 `data/liaohuiyi.db`（SQLite），不上传到任何服务器。删除该文件即可清空全部数据；备份该文件即可备份全部数据。

## 目录结构

```
server.js          Express 入口
lib/db.js          SQLite 初始化与建表
lib/parser.js       聊天文本解析器
routes/imports.js  导入/详情/删除/回收站/导出 API
routes/search.js   搜索 API
public/            前端页面（原生 HTML/CSS/JS，无需构建）
data/               本地数据库文件（自动生成）
```
